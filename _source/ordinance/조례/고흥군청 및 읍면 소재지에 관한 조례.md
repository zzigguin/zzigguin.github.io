# 고흥군청 및 읍면 소재지에 관한 조례

> 제정 1984.02.03 조례 제952호  
> 개정 1986.04.11 조레 제1074호  
> 1988.03.29 조례 제1159호  
> 1989.03.30 조례 제1225호  
> 1990.06.18 조례 제1281호  
> 1990.07.06 조례 제1285호  
> 1994.04.12 조례 제1451호  
> (일부개정) 1997.11.10 조례 제1646호  
> (일부개정) 2009.04.10 조례 제2091호 (고흥군 조례제명 띄어쓰기 등 일괄개정 조례)  
> (일부개정) 2012.06.14 조례 제2225호  
> (일부개정) 2023.04.04 조례 제2972호

### 제1조(목적)

이 조례는 「지방자치법」 제9조의 규정에 의하여 고흥군청 및 읍면소재지 위치를 정함을 목적으로 한다.

### 제2조(위치)

고흥군청 및 읍면위치는 다음과 같다.

┌─────────────────┬─────────────────────────┐

│ 군·읍·면 명 │ 소 재 지 │

│ │ │

├─────────────────┼─────────────────────────┤

│ 고 흥 군 청 │ 고흥군 고흥읍 고흥군청로 1 │

│ 고 흥 읍 │ ″ 고흥읍 터미널길 11 │

│ 도 양 읍 │ ″ 도양읍 녹동남촌 2길 14 │

│ 풍 양 면 │ ″ 풍양면 풍양로 5 │

│ 도 덕 면 │ ″ 도덕면 고흥로 499 │

│ 금 산 면 │ ″ 금산면 거금중앙길 84 │

│ 도 화 면 │ ″ 도화면 오치길 37 │

│ 포 두 면 │ ″ 포두면 우주로 597 │

│ 봉 래 면 │ ″ 봉래면 나로도항길 16 │

│ 동 일 면 │ ″ 동일면 양화길 8 │

│ 점 암 면 │ ″ 점암면 모룡길 48 │

│ 영 남 면 │ ″ 영남면 해맞이로 10 │

│ 과 역 면 │ ″ 과역면 송학큰길 52 │

│ 남 양 면 │ ″ 남양면 남양희망길 19 │

│ 동 강 면 │ ″ 동강면 서민호길 9 │

│ 대 서 면 │ ″ 대서면 동서로 464 │

│ 두 원 면 │ ″ 두원면 두원로 480-1 │

└─────────────────┴─────────────────────────┘
